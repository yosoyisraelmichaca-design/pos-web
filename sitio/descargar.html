Control Total POS para Windows

Cobra desde tu computadora aunque se vaya el internet. La app se actualiza sola cuando hay versiones nuevas.

⬇ Descargar para Windows

Instalador para Windows 10 y 11 (64 bits).

Cómo instalarla

  1. Toca Descargar para Windows y abre el archivo ControlTotalPOS-Setup.exe cuando termine de bajar.
  2. Si Windows muestra «Windows protegió su PC», toca Más información y después Ejecutar de todas formas.
  3. Sigue los pasos del instalador. No pide permisos de administrador.
  4. Abre Control Total POS desde el escritorio o el menú Inicio y entra con el mismo correo y contraseña de tu cuenta.

El aviso de Windows aparece porque la app todavía no tiene firma digital de Microsoft. Descárgala solo desde esta página.

Actualizaciones

Cuando hay una versión nueva, la app muestra una barra azul con el botón Actualizar. Se descarga, se instala y se vuelve a abrir sola. Tus datos no se tocan.

¿Usas celular o tableta?

No necesitas descargar nada: entra al sistema desde el navegador.
